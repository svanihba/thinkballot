{{ _("Bias Buster") }}

{{ _("Bias Buster checks every piece of text we write and every AI answer before you see it. Two jobs: no bias and no made-up facts.") }}

  1. {{ _("Quote check. Every point in an answer must quote the official text, and the quote must be found there word for word. If it isn't, the point is removed.") }}
  2. {{ _("Number check. Every number, dollar amount, percentage or date must appear in the official text.") }}
  3. {{ _("Loaded-word check. Persuasive words like \"disastrous\" or \"common-sense\" are caught unless the official text itself uses them.") }}
  4. {{ _("Balance check. When both sides are covered, YES and NO must both be there, at similar length.") }}
  5. {{ _("AI review. A second AI model reviews each answer for one-sided framing, hints about how to vote, and claims the source doesn't support. Its edits go through checks 1 to 4 again. If the review can't run, the answer is held back.") }}

{{ _("The site sets one cookie, only to protect its forms.
